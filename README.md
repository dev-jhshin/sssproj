
## 프로젝트 소개
> 학습 내용을 요약하고 복습할 수 있으며, 사용자 간 지식 공유에 초점을 둔 학습 커뮤니티 웹 사이트

- 학습한 내용을 정리하며 복습 효과 향상
- 사용자 간 지식 공유를 통한 학습 문화 조성
- 커뮤니티를 통해 정보 교류
- 신고/문의 기능을 통해 사이트의 건전한 운영 유지

## 역할 소개
- 팀장: 신지혜(BE/DB) - 커뮤니티, 마이페이지, 고객센터
- 팀원: 이서현(BE/DB) - 학습 게시판
- 팀원: 임경근(BE/DB) - 로그인 및 회원가입, 관리자 페이지
- 팀원: 이동규(FE) - 로그인 및 회원가입, 관리자 페이지, 고객센터, 시연 영상 제작
- 팀원: 추수민(FE) - 학습 게시판, 커뮤니티, 테스트 케이스 작성

## 주요 기능
**사용자 기능**
- 회원 가입 / 로그인

**학습 노트 작성 및 공유**
- 학습 노트 작성
- 분야, 해시태그별 학습 자료 분류
- 공개, 비공개 설정
- 오늘의 학습 표시 여부 -> 매일 학습 및 복습 지원
- 공유 학습 -> 개인과 개인 간의 학습 내용 공유

**검색**
- 키워드 기반 검색(제목, 내용, 작성자, 해시태그, 분야)
- 인기 학습 노트 (좋아요 기반)
- 최신 업데이트 학습 노트

**커뮤니티**
- 학습 노트 외 자유로운 소통을 위한 커뮤니티 전용 게시판
- 비로그인 사용자도 볼 수 있지만, 작성/수정/좋아요 등 활동은 제한된다.

**고객센터**
- 문의 내역 조회 및 문의 글 작성

**관리자 기능**
- 문의 및 신고 처리
- 부적절한 활동을 한 사용자 정지
